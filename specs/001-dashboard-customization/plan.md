# Implementation Plan: Dashboard Customization

**Branch**: `001-dashboard-customization` | **Date**: 2026-03-21 | **Spec**: [spec.md](spec.md)
**Input**: Feature specification from `/specs/001-dashboard-customization/spec.md`

## Summary

Add three user-facing customization capabilities to the home lab dashboard: (1) per-metric donut/gauge charts rendered using the existing recharts library, (2) drag-and-drop card reordering via `@dnd-kit/sortable`, and (3) full add/remove control over metrics per card. Layout is persisted to `localStorage` under a new `dashboard-layout-v2` key to accommodate the updated schema.

## Technical Context

**Language/Version**: TypeScript 5.3, React 18, Node.js v24 (NVM)
**Primary Dependencies**: recharts (existing — donut gauges), @dnd-kit/core + @dnd-kit/sortable (new — drag and drop), Tailwind CSS v3, lucide-react
**Storage**: `localStorage` key `dashboard-layout-v2` (browser only, no server storage)
**Testing**: None (per constitution — personal tool)
**Target Platform**: Modern browser (desktop + mobile), served by Node.js Express on Linux
**Project Type**: Web application (React SPA served by Express backend)
**Performance Goals**: Gauge renders within 1 second of saving chart type; drag feels responsive at 60fps
**Constraints**: Single Node.js process deployment; no new backend changes required; touch drag support required
**Scale/Scope**: Single user, 6–12 cards typical, up to ~20 metrics total
