# Implementation Plan: Docker Container Hyperlinks

**Branch**: `002-container-links` | **Date**: 2026-03-21 | **Spec**: [spec.md](spec.md)
**Input**: Feature specification from `/specs/002-container-links/spec.md`

## Summary

Add clickable hyperlinks to Docker container names in the containers table. Each running container with published ports gets a `webUrl` field computed on the backend (or agent) from its port bindings and optional `dashboard.url` Docker label. The frontend renders the name as an anchor tag that opens in a new tab. No new dependencies required.

## Technical Context

**Language/Version**: TypeScript 5.3, React 18, Node.js v24 (NVM)
**Primary Dependencies**: dockerode (existing — already reads container port bindings)
**Storage**: None — URLs are derived at request time from Docker state
**Testing**: None (per constitution — personal tool)
**Target Platform**: Modern browser + Node.js Express on Linux
**Project Type**: Web application (React SPA served by Express backend)
**Performance Goals**: No measurable impact — URL derivation is O(n) on port count, negligible
**Constraints**: No new dependencies; backend and agent must both implement URL derivation
**Scale/Scope**: Single user, up to ~50 containers typical
